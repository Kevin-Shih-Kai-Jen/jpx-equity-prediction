# Evaluation protocol

## Scope and provenance

This is one completed, fixed-seed historical expanding-window experiment, evaluated from saved predictions. It is not a submitted Kaggle score. Frozen source: https://github.com/Kevin-Shih-Kai-Jen/jpx-equity-prediction/tree/b3cd1bfd617251c7eebc42c588e4067a09af1fe3 . Full parameters and hashes are in `experiment_config.json` and `artifacts.json`.

Eight complete 180-calendar-day validation intervals are generated by the original split loop. Evaluated Target dates span 2017-06-30 through 2021-06-08, with 958 dates and 1,850,796 security-date samples after row/window filtering. The trailing partial interval is not evaluated. The model and Adam optimizer continue across folds; these are not eight independently initialized trials.

The original preprocessing validates required rows, adjusts prices, fills missing ExpectedDividend with zero, and normalizes features on each training partition. Scaling is fit before removing the last two training dates; the purged dates' labels are not used for model fitting. Validation receives up to 41 earlier input rows per security. Exact split boundaries, scaler values and actual purged training dates are recorded in the configuration. This report preserves these choices and makes no claim that every possible source of research bias has been eliminated.

## JPX task and submission distinction

JPX evaluates the Sharpe ratio of daily rank-weighted long-short spreads, using the top 200 and bottom 200 securities. The supplied Target represents the next-day purchase / following-day sale return. The competition API requires a unique integer Rank from 0 through N-1 for each supplied row, without reordering the rows. [1,2]

The repository implements an offline historical calculation. Its internal pandas ranks start at 1 and average tied values; they are not a ready-to-submit Rank column. Ranking ties, universe coverage, API format and prediction timing still require an end-to-end submission check. Full competition-rule compliance is not asserted here. All primary reported Sharpe values are based on this repository's original calculation.

## Exact project portfolio and metrics

On each date, sort securities by ascending internal Prediction_rank (best prediction first). Let q = linspace(2, 1, 200). Give the top 200 weights +0.5*q/sum(q). Give the bottom 200 weights -0.5*reverse(q)/sum(q). All other weights are zero. Long absolute weights sum to 0.5, short absolute weights sum to 0.5, and total gross exposure is 1.

For each date t:

```text
r[t] = sum_i(w[i,t] * Target[i,t])
Sharpe = mean(r) / sample_std(r, ddof=1)
earnings = sum_t(r[t])
Rank IC[t] = Spearman(Prediction[:,t], Target[:,t])
mean Rank IC = mean of defined daily IC values
MAE = sum(abs(Prediction - float32(Target))) / number of samples
```

The original evaluation stores daily returns as float32 and uses float32 reductions within a fold. Reported fold Sharpe and earnings retain those saved values. The pooled Sharpe is recomputed over all 958 stored daily returns in float64, not by averaging fold Sharpe ratios. The sum of saved fold earnings is 0.2359505807980895; the float64 sum of the daily series is 0.2359505802228341. The 5.75e-10 difference is rounding, not a different strategy.

The normalization of raw spread returns must be disclosed when comparing earnings across implementations. A constant positive rescaling leaves Sharpe unchanged only when daily selections, ordering and all other conventions are identical. Exact equivalence to the competition's full scoring implementation has not been certified.

The one undefined IC date, 2020-09-29, has constant supplied Target (all zero). The evaluated sample includes 1,973 securities and 1,973 distinct predictions. The original mean excludes this undefined correlation; the pooled mean therefore uses 957 dates. This is not constant model output.

## Units and diagnostic measures

- **Gross spread sum:** daily long-short returns added together before costs. It is not a compounded net return or investor NAV growth.
- **bp / bps:** basis point(s). 1 bp = 0.01% = 0.0001 in decimal-return units.
- **pp:** percentage point(s), a difference on a percentage scale. The additive sum 0.23595 is shown as 23.595 pp; it is not claimed as a 23.595% compounded investment gain.
- **Sharpe:** daily average spread divided by its sample standard deviation, with base return zero. All primary scores are non-annualized.
- **Annualized reference:** daily Sharpe * sqrt(252) = 1.5787, under an IID/no-serial-correlation convention. Daily lag-1 autocorrelation is 0.1273; this number is not autocorrelation-adjusted. [3]
- **Rank IC:** daily cross-sectional Spearman rank correlation, averaged over defined dates. This is a diagnostic, not the competition's primary score.
- **Zero baseline MAE:** error from predicting zero Target for every sample. It is not a ranked-trading baseline.
- **Additive maximum fall:** maximum peak-to-trough decline in cumsum(r), including a zero starting point. It is not percentage drawdown of a compounded wealth process.

## Cost sensitivity (secondary analysis)

```text
weight_change[t] = sum_i(abs(target_weight[i,t] - target_weight[i,t-1]))
scenario_return[t] = r[t] - cost_bps * 0.0001 * weight_change[t]
```

Start flat, carry target weights across fold boundaries, and add closing the final portfolio to the final day's change. Costs scale with both long and short traded target notionals. The break-even rate is 2.3308 bp per traded notional in this simplified calculation. It excludes price drift, marked-to-market rebalancing, actual fills, liquidity limits, borrowing, taxes and operational constraints. The scenarios are not realized net returns and do not change the original JPX-style primary score.

## Interpretation limits

One seed, one architecture and one historical path do not establish statistical significance or future profitability. Performance is uneven across periods; folds 3 and 5 contribute 50.98% of the total additive spread sum. No hyperparameter search on an independent final holdout is presented. Multiple seeds, a separate untouched period and ranking baselines are sensible next experiments, not completed results.

Completion was audited from all eight evaluations, 160 completed epochs, finite prediction files, continued Adam step counts and matching final-model tensors/normalization. The first 15 training epochs lack original cumulative loss counters, so the exact full-fold training mean for fold 1 is unavailable. Validation metrics and saved model states are present; training loss is not used as evidence of complete backtest performance.
